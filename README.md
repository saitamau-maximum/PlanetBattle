# 操作方法

キーボードとマウスで操作します。左右移動・ジャンプ・攻撃には、以下の代替キーも使えます。

| 操作 | キー・ボタン | 説明 |
| --- | --- | --- |
| 左右移動 | **A / D** | 移動方向にプレイヤーが向きます。 |
| ジャンプ | **Space** / **W** | 押す長さでジャンプの高さを調整できます。 |
| 攻撃・建造 | **左クリック** | 攻撃モードでは選択中の武器で攻撃し、建造モードでは選択中の建造物を配置します。 |
| 武器スロット1を選択 | **E** | 対応する武器を選び、攻撃モードに切り替えます。 |
| 武器スロット2を選択 | **R** | 対応する武器を選び、攻撃モードに切り替えます。 |
| 建造物スロットを選択 | **1 / 2 / 3 / 4** | 対応する建造物を選び、建造モードに切り替えます。 |
| 建造物を削除 | **Q** | 正面の削除アイコンが表示された建造物を削除し、建造コストをCoinとして返金します。 |
| 味方を召喚 | **Ctrl** | Experienceを消費して、次の味方を召喚します。 |

## 建造の流れ

1. **1〜4**で建造するスロットを選択します。
2. 配置可能な場所で**左クリック**を押すと、Coinを消費して建造を開始します。
3. 建造完了まで待つと、建造物が使用可能になります。
4. **E / R**で武器を選ぶと、攻撃モードに戻ります。配置後も建造モードは継続します。

## 建造物の削除

建造物に近づいて正面を向くと、削除可能な対象にアイコンが表示されます。**Q**でその建造物を削除できます。攻撃モード・建造モードのどちらでも操作できます。

- 現在は体力が**100%**の建造物のみ削除できます。
- 削除すると建造時に消費したCoinが返金されます。ただし、所持上限を超える分は受け取れません。
